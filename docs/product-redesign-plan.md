# 수급 연구소 제품 구조·개발 계획 재검토

검토 기준일: 2026-10-25 (Asia/Seoul). 현재 App, TrackingCases, Simulation, 상세 패널, v2 점수 코드 및 이전 데이터 품질 감사 결과를 검토했다. 이 문서는 개발 계획이며 운영 구현 완료를 뜻하지 않는다.

## 1. 이번 재검토에서 수정한 점

- 기능을 메뉴별로 하나씩 추가하는 방식 대신 ‘시장 파악 → 종목 발굴 → 신호 추적 → 전략 검증’으로 사용자 흐름을 구성한다.
- RSI·신고가를 독립적인 최상위 메뉴로 계속 늘리지 않는다. 현재 종목 상태는 종목 발굴에서, 날짜가 있는 발생 사건은 신호 추적에서 본다.
- 현 코드의 기본 정렬은 이미 signal_date 내림차순이다. 로직을 다시 만드는 대신 ‘신호 발생일 최신순’으로 명칭을 고치고 같은 날짜의 동점 정렬을 명시한다.
- 현재 상단 1/2/3개월 선택은 추적에 적용되지 않는다. 전역 날짜처럼 보이는 컨트롤을 페이지별 의미가 분명한 컨트롤로 옮긴다.
- 3년 최고가를 역사적 신고가로 부르지 않는다. Cutler RSI와 기존 연구의 Wilder RSI를 같은 지표로 취급하지 않는다.
- 기업행사는 수정주가 하나로 해결되지 않는다. 실제 계좌의 수량, 거래 가능한 수량, 미상장 권리, 현금 및 종목 변경을 처리해야 한다.
- 기존 연기금 신호·점수 v2·매매 규칙을 새 순위 점수와 조용히 교체하지 않는다. 규칙 버전과 데이터 기준을 명시한다.

## 2. 최상위 화면 4개

| 화면 | 사용자가 하는 일 | 주요 내용 | 다음 행동 |
|---|---|---|---|
| 시장 현황 | 오늘 어떤 시장인지 파악 | 기관합계·연기금·사모 수급, 4개 지수 및 Cutler RSI, 관련 데이터 기준시각 | 투자자/지수 선택 → 종목 발굴의 해당 조건으로 이동 |
| 종목 발굴 | 지금 조건에 맞는 종목 비교 | 수급 순위 / RSI / 신고가 보기, 관심 종목, 시장·대상군·기간 필터 | 종목 선택 → 공통 상세, 조건 저장 |
| 신호 추적 | 발생한 사건의 이후 경과 관찰 | 연기금 신규 신호·RSI 30 하향 진입·신고가 돌파, 신호 날짜와 규칙, 수익/도달 결과 | 이벤트 선택 → 당시 전후 상세, 검증 조건으로 전달 |
| 전략 검증 | 매매 규칙과 자금 운용 비교 | 입력 조건, 데이터 신뢰도, 계좌 결과, 기준 전략 비교, 거래 기록 | 거래 선택 → 실제 보유 구간 상세 |

현재의 상시 왼쪽 패널은 다시 만들지 않는다. 데스크톱은 간결한 상단 탐색, 모바일은 4개 메뉴에 쉽게 접근하는 배치를 사용한다. 별도의 ‘작업 일정’ 메뉴를 고객용 주 화면에 추가하지 않는다.

### 공통 헤더

- 서비스 이름, 종목 검색, 관심 종목 접근, 테마 및 계정.
- 수집 실행은 관리자에게만 제공하며 일반 사용자의 주 행동보다 앞에 배치하지 않는다.
- 데이터 기준은 페이지와 항목에 맞게 표시한다. 한국·미국 자료를 하나의 기준일로 표시하지 않는다.
- 상세 데이터 상태는 펼침 영역에서 제공하고, 해당 화면 결과에 영향을 미치는 오류만 눈에 띄게 알린다.

## 3. 상태와 사건을 구분

### 종목 발굴 = 현재 상태

- RSI 30 미만: 마지막 유효 종가 기준으로 현재 30 미만인 상태.
- 수급 상위: 선택한 동일 기간의 전체 대상 순위.
- 신고가 근처/신고가 갱신: 명시한 가격 기준과 관찰 범위의 상태.

### 신호 추적 = 발생 사건

- RSI 진입: 직전 유효 거래일 RSI >=30, 해당 거래일 RSI <30. 계속 30 아래에 있다고 매일 새 신호를 생성하지 않는다.
- 신고가 돌파: 해당 날짜의 가격이 직전 날짜까지의 최고가를 넘은 사건. 단순 동가·연속 갱신·재돌파 정책을 버전으로 정의한다.
- 같은 종목에 여러 종류의 신호가 같은 날 생기면 한 행에 배지로 묶고, 필요한 경우 사건을 펼쳐 본다. 규칙별 상세는 보존한다.
- 등록 조건 충족, 이후 수급 상태, 가격 도달 결과를 서로 다른 필드로 보관한다. 나중에 매도됐다는 이유로 과거 등록 사건을 지우지 않는다.
- 사건 키는 종목 ID + 규칙 버전 + 발생일이다. 같은 종목을 실제로 중복 매수하지 않는 계좌 규칙은 별도로 적용한다.

### 화면별 기간

| 화면 | 기간의 의미 |
|---|---|
| 시장 현황·수급 발굴 | 순매수 집계 기간: 최근3달 고정 및 실제 거래일 수(2026-10-28 사용자 변경 반영) |
| RSI 발굴 | 계산 길이(기본14), 가격 기준일, 대상 시장/종목군 |
| 신호 추적 | 신호 발생일 범위: 최근5일·최근10일·전체·사용자 범위 |
| 전략 검증 | 신호 선택 시작/종료일, 별도 지표 계산용 과거 준비 구간 |

필터·정렬·페이지·스크롤은 화면 이동이나 상세 열기/닫기 후 유지한다. 필요하면 URL에 조건을 담아 같은 분석으로 돌아오게 한다.

## 4. 8항목 수급 점수의 데이터 계약

확정 요구: 외국인·기관합계·연기금·사모 × 절대금액 순위와 시총 대비 상대비중 순위.

1. 절대값 = 선택 기간 순매수금액.
2. 상대값(%) = 선택 기간 순매수금액 / 명시한 기준일 시가총액 ×100.
3. 각각 같은 시장 범위·같은 기간의 전체 대상에서 내림차순 순위를 계산한다.
4. 화면 검색·업종·시총 필터는 순위 계산 이후 적용한다. ‘현재 검색 결과 중 순위’로 바뀌면 안 된다.
5. 기본 비교 모집단은 국내 KOSPI+KOSDAQ의 정의된 주식 범위이며, KOSPI/KOSDAQ 별도 순위는 별도 항목으로 명확하게 제공한다. 미국 종목과 국내 순매수 순위를 섞지 않는다.
6. 동점은 같은 중간 순위를 사용하고 기준 종목 수와 결측 수를 함께 기록한다. 순매수 0·음수는 그대로 표시하되 ‘매수 강도’ 점수에서는 양의 순매수에만 가점을 부여하는 기준안을 검증한다.
7. 시총 또는 투자자 자료가 없으면 상대값/점수도 미확인이다. 부족한 항목의 가중치를 다른 항목에 자동 재분배해 총점을 높이지 않는다.
8. 초기 동일 가중치(8항목 각각12.5점)는 비교용 가설이다. 사용자가 승인한 것은 8항목 구성이며 최적 가중치가 확정된 것은 아니다.
9. 기관합계에 연기금·사모가 포함되는 점을 표시한다. 요청한 8항목을 임의로 삭제하지 않고, 부모·자식 항목의 상관과 가중치 민감도를 검증한다. 네 수급을 단순 합해 전체 매수액으로 제시하지 않는다.
10. 표시 명칭은 수급 강도 점수로 하며 검증된 수익 확률처럼 표현하지 않는다. 기존 v2와는 버전·계산식을 구분한다.

### 상세 점수 화면

목록에는 총점·상위 비율·자료 충족 상태만 간결하게 표시한다. 상세에는 투자자4행 × 절대/상대2열로 금액, 비중, 전체 순위, 반영 점수를 보여준다. 설명 전문은 도움말로 옮긴다. 표에 8개 순위 열을 항상 늘어놓지 않는다.

### 과거 검증

당시 전체 종목 모집단, 당일 이용 가능 수급, 당시 시총으로 과거 점수를 재생성해야 한다. 현재 시총과 현재 상위30종목으로 과거 시점을 재구성하지 않는다. 가격 이력만3년 있다고 새 스코어의3년 검증이 가능한 것은 아니다.

## 5. 데이터 수집 확장과 시장 범위

- 기관합계·사모 수집을 추가하기 전에 기존2종 투자자 수집·검증·게시 경로의 허용값, 일별 커버리지, 재시도, 과거 파일 호환성을 확장한다.
- 기존 운영 수집을 깨뜨리지 않도록 새 투자자 자료는 별도 검증 후 게시한다. 실제0과 응답 실패를 분리한다.
- 우선 최근 자료를 검증하고 이후 필요한 과거 수급과 시점별 시총을 함께 적재한다.
- 국내 주식 전체 지표 계산 범위와 미국 지표 계산 범위를 구분한다. 미국 초기 범위는 지수와 시총 상위30개 주식이다. 미국 전체 주식 수집까지 임의 확장하지 않는다.
- 상위30개는 기준일별 시총 선정 목록과 출처를 저장한다. 발행회사 기준인지 주식종류 기준인지, ADR·복수상장 처리도 명시한다. 최초안은 회사 중복을 제거한 보통주 중심이며 현재 보유 자료의 과거 분류는 별도 검증이 필요하다.
- 미국 OHLC·시총·기업행사 자료 제공처의 실제 커버리지·사용 조건·갱신 시각·비용을 확인한 뒤 연결한다. 지수 자료만으로 미국 개별종목 RSI를 계산할 수 없다.
- 종목 식별자를 시장+코드로 확장한다. 기존 국내6자리 코드·관심목록은 호환시키고 미국 티커나 지수를 기존 국내 정규식에 억지로 넣지 않는다.

## 6. Cutler RSI·신고가의 정확한 의미

### Cutler RSI

- 기본14개 종가 변화(최소15개 유효 종가)의 상승·하락 폭 단순평균을 사용한다. 기존 Wilder 연구 결과를 Cutler 결과로 재사용하지 않는다.
- 국내·미국 거래일과 시간대를 분리한다. 데이터 지연과 휴장일을 혼동하지 않는다. 아직 마감되지 않은 미국 당일 종가를 한국 오전 매수 판단에 사용하지 않는다.
- 처음에는 일봉 마감 기준 모니터링이다. ‘현재 RSI’도 마지막 마감 자료 기준이며 실시간 진입 알림으로 부르지 않는다.
- 과매도 상태와 30 재돌파 회복은 다른 이벤트다. RSI<30을 자동 매수 권고로 표시하지 않는다.

### 신고가

- 52주 최고가 / 수집 범위 최고가 / 상장 이후 역사적 최고가를 구분한다.
- 역사적 신고가를 확정하려면 상장 이후 가격 범위와 기업행사 조정 기준을 검증한다.3년 자료만 있으면 ‘3년 관측 최고가’로 표시한다.
- 종가 돌파와 장중 고가 돌파를 구분한다. 최초안은 종가 기준 돌파를 기본으로 하되 장중 조건도 별도 이름으로 제공한다.
- 액면분할·무상증자·회사분할 전후의 가격을 무조정으로 비교해 거짓 신호를 만들지 않는다.

## 7. 공통 종목 상세의 정보 우선순위

1. 종목명·시장·가격과 가격 기준시각.
2. 선택한 사건의 규칙·발생일·당시 기준값, 모의 거래면 실제 진입·청산일 및 수익.
3. 신호 이전20/이후40거래일 기본 구간. 청산이 더 늦으면 청산 이후10거래일까지 자동 확장. 충분한 앞뒤 자료가 없으면 표시한다.
4. 연기금·기관·사모·외국인 수급과 일봉을 동일 날짜 축으로 비교. 신호/진입/청산 표시를 유지한다.
5. 수급8항목 점수, RSI·신고가 근거, 가격·기업행사 상태를 접이식 근거 영역에 둔다.

현재 가격과 당시 매매 수익을 같은 수익률처럼 보이게 배치하지 않는다. 추적의 독립 +30/-10 최초 도달과 현금 대기 후 실제 진입한 시뮬레이션 결과는 기준이 다르므로 출처와 진입일을 각각 보여준다.

## 8. 미확인 계산을 다루는 방식 수정

- 현재4건 원금11,862,500원의 재현 사례는 가격 단절·거래정지·기업행사로 구분해 감사한다.
- 단순 거래량0만으로 거래정지로 확정하지 않는다. 공시·거래 상태와 원천 응답을 확인한다.
- 확인된 거래정지는 보유를 유지하고 매매를 하지 않는다. 재개 후 시가 갭과 예약 주문을 실제 가능한 시점에 반영한다.
- 액면분할은 수량·평단·단주를 함께 조정한다. 무상증자 권리는 권리락 시점의 미상장 배정 권리와 신주 상장 후 매도 가능한 수량을 구분한다. 인적분할은 신설 주식과 현금 정산을 별도 자산으로 처리한다.
- 원자료 누락은 검증 가능한 다른 제공처로 보완하고 출처와 변경 이력을 남긴다. 기업행사를 가격 한 칸 수정해 숨기지 않는다.
- 거래정지 중 마지막 가격을 참고 평가에 사용할 수 있으나 체결가·확정 평가로 둔갑시키지 않는다. 참고 평가와 확정 가능한 손익을 나누어 표시한다.
- 현금 / 확인된 보유가치 / 거래정지·기업행사 정산 대기 / 미매수를 구분한다. ‘미확인’을 모든 null값에 공통 출력하지 않는다.
- 미확인 종목을 사후 제외한 깨끗한 결과를 원래 전략 성과로 제시하지 않는다. 제외 비교가 필요하면 별도 시나리오로 표시한다.

## 9. 성능·접근성·운영 관점

- 메뉴를 열 때 전체3년·전체 종목 원자료를 다시 받지 않는다. 미리 계산한 목록/순위와 필요한 종목·기간만 요청한다.
- 현재 병렬 요청·세션 캐시는 유지하되, 새 데이터 버전으로 갱신되면 이전 캐시를 구분한다. 시뮬레이션 계산은 작업 스레드에서 수행한다.
- 로딩은 표·차트 자리에서 같은 크기의 스켈레톤과 짧은 상태 문구를 사용한다. 첫 데이터 요청과 조건 재계산을 구분한다.
- 본문14px 내외, 표·입력13px 내외를 기준으로 기존 테마를 맞추고 모바일에서8~9px로 축소해 모든 열을 구겨 넣지 않는다. 모바일은 핵심값과 펼침 상세를 우선한다.
- 수급 매수/매도 색상과 RSI 상태 색상의 의미를 혼동하지 않게 한다. 색상 외 문구·기호도 제공한다.
- 기존 로그인·관리자 수집·다운로드 차단·비공개 원자료 구조를 유지한다. API에서도 권한을 확인한다.
- 새 데이터 또는 계산 실패 시 마지막 정상 자료의 기준일과 제한을 표시한다. 이전 정상 자료를 오늘 자료처럼 표시하지 않는다.

## 10. 수정된 개발 순서와 완료 기준

| 단계 | 작업 | 완료 기준 |
|---|---|---|
| 1 | 지표 정의·화면 구조·종목 ID/데이터 계약 고정 | 네 화면의 역할, 기간, 사건 키,8항목 순위 기준, Cutler·신고가 정의 문서화 |
| 2 | 현재 미확인4건과 기업행사·거래 상태 처리 | 실제 감사 근거, 합성 체결 없는 재계산, 현금/수량/권리 검증; 남은 미확인은 명시 |
| 3 | 공통 상세·타이포·로딩·정렬 명칭·상태 유지 개선 | 현재 기능을 재사용한 로컬 검증, 과거 사건과 실제 거래 구간 확인 |
| 4 | 기관합계·사모 및 기준일 시총 수집·순위 게시 | 새 자료 실제 검증, 기존 수집과 호환, 전체모집단 순위/커버리지 저장 |
| 5 | 시장 현황·수급 발굴·8항목 비교 점수 연결 | 수집한 실제값만 노출,8항목 근거와 버전 표시, 포함 관계와 합계 구분 |
| 6 | 국내 전체·지수 Cutler RSI → 미국 상위30 → 신고가 | 시장별 데이터 검증, 상태/진입 사건 구분, 시총30 구성 이력, 역사적 범위 표시 |
| 7 | 통합 신호 추적과 전략 비교 | 같은 날 중복 신호·재진입·현금제약 처리, 당시 데이터만 사용한 점수·조건 검증 |
| 8 | 단계별 운영 반영·검증 | 로컬 확인 후 배포, 데이터·권한·성능·모바일·테마·장애복구 확인 |

새 기능이 수집되지 않은 상태에서 빈 메뉴만 대량 배포하지 않는다. 사용할 수 있는 데이터 단위로 수직 기능을 완성해 단계적으로 반영한다. 모든 개발이 끝나야 작은 개선까지 배포하는 일괄 출시도 피한다.

전략 비교는 기존 +30/-10 기준, -7/-8 손절, 연기금 매도 후 다음 날 청산 등을 버전별로 비교한다. 기존에 이미 탐색한2026년을 새로운 독립 검증 표본이라고 부르지 않는다. 이후 쌓이는 자료로 전진 검증하고 비용·현금 노출·비교 지수 조건을 맞춘다. 미국 종목은 우선 모니터링 범위이며 실제 다중 통화 시뮬레이션은 환율·거래시간·수수료 모델이 준비된 뒤 별도로 확장한다. 실제 자동매매는 이번 개발 범위에 넣지 않는다.
