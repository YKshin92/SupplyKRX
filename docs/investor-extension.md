# 기관합계·사모 수집 확장

2026-10-26. 하루 실제 원천 사전검증과 최근2거래일 비공개 적재/운영 갱신 확인 완료. 기관·사모 화면과8항목 점수는 후속 구현 중이다.

## 자료 계약

기존 CSV 열과 연기금/외국인 경로를 유지한다. 투자자 레이블/pykrx 인수/보호된 웹 경로는 다음과 같다.

| 저장 레이블 | pykrx 인수 | 웹 하위 경로 |
|---|---|---|
| 연기금 등 | 연기금 | 기존 루트 |
| 외국인 | 외국인 | foreign |
| 기관합계 | 기관합계 | institution |
| 사모 | 사모 | private-fund |

pykrx의 [공식 구현](https://github.com/sharebook-kr/pykrx/blob/master/pykrx/website/krx/market/wrap.py)의 투자자별 순매수상위종목 함수는 기관합계7050/사모3100을 지원한다. 실제 현재 원천 응답은 별도로 검증해야 한다. 기관합계는 연기금·사모를 포함하므로 네 금액을 단순 합산하지 않는다. manifest에 부모/구성 분류와 설명을 기록한다.

기존 과거 파일에 기관/사모 행이 없으면 미수집이다. 그 날짜의 행을 생성하거나0으로 채우지 않는다. 성공한 시장 응답에 종목이 빠진 경우에만 기존 absent_zero 정책을 적용하며, 원천 전체 응답 실패는 수집 실패로 남긴다. 기존0/결측/거래정지 정책을 변경하지 않는다.

## 기준일 시총

각 수집 거래일에 업종·시가총액을 조회해 `data/live/metadata/daily/YYYY-MM-DD.json`에 별도 저장한다. 날짜/종목/시총/출처를 배치 전체 검증한 다음 기록하고, 화면용 calendar.instruments는 최신일 자료만 유지한다. 과거 파일의 시총이 없을 때 최신 시총을 역으로 채우지 않는다. 이 sidecar는 비공개이며 공개 코드나 CSV 열에 실제 원자료를 넣지 않는다.

## 호환과 운영 준비

- 공통 투자자 정의를 수집기·검증기·게시기·기간별 projection·신선도 판정에서 사용한다.
- 2투자자 과거 파일은 그대로 읽을 수 있다. 네 투자자 자료가 미비하면 중복 수집 건너뛰기나3일 overlap 최적화로 최초 확장을 생략하지 않는다.
- 수급8항목 순위/점수와 기관·사모 화면은 아직 연결하지 않았다. 전체 모집단과 기준일 시총의 실제 커버리지 검증 후 구현한다.
- 운영 활성화 전 비공개 workflow가 어느 코드 ref의 수집기/신선도 스크립트를 쓰는지 확인하고 작은 실제 수집으로4투자자·시총 날짜를 검증한다. 대량 과거 적재는 검증 후 이어간다.
- KRX 로그인·수집 관리자 권한·다운로드 차단·비공개 저장 구조는 유지한다.

검증: 4투자자 분리 게시, 레거시 일자의 신규 투자자 행 미생성, 실제0 유지, 초기 수집/시장별 누락, 날짜 불일치 시총 거부와 파일 미생성, 기관 포함관계. 이 단계의 자동 테스트는 합성 경계값이며 실제 수집 성공을 뜻하지 않는다.

실제 검증: 격리 사전검증40293062156 성공 후 정상 수집40296585878 성공, 저장907b09bb/과거 projection06e0a7ec. 기관합계·사모 각각2,602종목×2거래일=5,204행.2026-10-26 CSV의 실제 blob을 다시 읽어 KOSPI801/KOSDAQ1801×4투자자10,408행을 확인했다. 해당일 시총 snapshot2,764개는 모두 metadata_date 일치하며 순매수 수집대상2,602개와는 범위가 다르다. 시총 snapshot 전체를 보통주 순위 모집단으로 그대로 사용하지 않는다. 기관·사모의 과거 미수집 날짜는 그대로 남아 있다.

로컬 `flow_ranks.py`는 명시적으로 받은 전체 모집단에서8항목 중간순위/유효 N/시총비중/동일12.5점 가설을 계산한다. 검색 필터는 계산 후 적용하며, 기간 수급 또는 기준일 시총이 없으면 총점null로 남기고 가중치를 재분배하지 않는다. 아직 보호된 생성물과 화면에 연결하지 않았으며 전략 가중치나 기존 v2를 변경하지 않는다.

## 2026-10-28 화면 연결

위의 ‘아직 연결하지 않았다’는 C1/C2 당시 기록이다. C3에서는 prepare-local 생성 경로와 시장 현황·종목 발굴 UI를 연결했다. 시장 현황의 기본3개 흐름은 기관합계·연기금·사모이며 외국인은 보조 펼침 영역에 둔다. 같은 날짜 축을 사용하고, 다른 기준일 자료는 합산 보류한다. 기관합계의 포함 관계는 항상 표시한다.

종목 발굴 → 수급 순위 ·8항목에서 최근일/1·2·3개월을 선택한다. 검색·시장·관심 조건은 결과 행만 줄이며 순위 N과 등수는 바뀌지 않는다. 정렬은 총점, 시총, 투자자별 절대금액/상대비중을 지원한다. 상세는4투자자×금액/비중의8개 값과 각 순위·분모·가점·거래일 확보 수를 보여준다. ‘수급·일봉 상세 보기’는 기존 차트로 연결한다.

점수는 동일 가중치 비교용이며 매수 관심 스코어 v2나 실제 매매 신호에 적용하지 않는다. 전체8항목 확보 시에만100점 만점 총점을 제공하고 기간 결측 시 보류한다. 원본/결과 파일은 비공개 배포 저장소와 로그인 보호 경로에만 둔다. 화면 연결과 기관/사모의 과거 수집 확장은 서로 다른 단계이며, 새 기간을 실제 적재하기 전에는 월간 총점 확보를 주장하지 않는다.
