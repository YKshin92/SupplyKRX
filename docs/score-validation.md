# 8항목 수급 점수 검증 기준

## 현재 완료와 미완료

최근3개월 투자자4종·기준일 시총·전체 모집단으로 현재 점수를 계산한다. 점수 자체의 계산 검증과 이후 수익에 대한 예측력 검증은 다르다.3개월 합계 점수를 과거 신호에 적용하려면 그 신호보다 앞선3개월 자료가 필요하며, 이후 수익 관찰 구간도 필요하다. 현재3개월 원자료만으로3년 전체의 같은 점수를 검증했다고 표현하지 않는다.

## 날짜별 관측 보존

`data/live/score-snapshots/YYYY-MM-DD/<generation>/`는 비공개 저장소에만 둔다. gzip으로 보관한8항목 전체 모집단과 기준일·시총비중·등수/N·총점, 실제 captured_at(시간대 포함), 거래일 목록의 원본 SHA-256 및 기준일 메타데이터/달력 지문을 저장한다. 같은 generation 재실행은 최초 시각을 덮어쓰지 않으며, 다른 계산 결과는 다른 generation으로 남긴다. 점수 수정 이력을 미래에 처음부터 알았던 것처럼 취급하지 않는다.

장 마감 당일16시 이후이며 모집단도 당일 관측된 경우에만 same_day_after_close로 분류한다. 과거 날짜를 나중에 기록한 것은 late_or_unverified_capture이며 전진 관측일 수에 포함하지 않는다. 당일 장 마감 전과 미래 날짜는 기록을 보류/거부한다. 수급 확정 여부는 unknown/unconfirmed이며 확정된 통계라고 표시하지 않는다.

기록은 주문·매매 결과나 확정 성공률이 아니다.20거래일 관찰 완료 수는 비교 준비가 된 ‘기록일’ 수이며 익절·손절을 완료한 거래 수가 아니다. 미래 수익률 같은 결과 필드가 점수 원본에 들어가면 저장을 거부한다. 위·변조된 gzip, 중복 종목, 잘못된 파일 경로와 커버리지 불일치를 검사한다.

새 시그널의 이후 성과를 검증할 때에는 관측 파일이 도입된 비공개 Git commit의 입력 자료와 SHA 지문을 사용한다. 후일 수정된 사건 목록으로 당시 진입 대상을 다시 선택하지 않는다. 당시에 존재한 후보와 결측도 보존해 비교하고, 실제 이용 가능 시각 이후에만 매수 후보로 인정한다. 현재 구현은 점수 관측 보존과 준비 현황이며 후보별 성과 집계는 아직 구현하지 않았다.

## 사전 비교안

1. 기존 v2 점수·매매 규칙을 기준으로 남긴다.
2. 같은 당시 신호/자금/익절+30%/손절-10%/진입 시각에서 매수 우선순위만8항목 동일 가중치 점수로 바꾼 안을 비교한다.
3. 전체 유효 모집단의 점수 상위20% 조건을 추가한 별도 안을 비교한다. 화면 필터 후 순위를 다시 계산하지 않는다.

당시 점수 미확인 표본은0점으로 바꾸지 않는다. 전체 기준 전략과 공통 자료 확보 표본의 비교를 함께 내어 결측 종목을 사후 제외한 효과를 구분한다. 기관합계가 연기금·사모를 포함하는 상관 구조와 가중치 민감도를 별도로 확인한다. 기존에 반복 탐색한 기간은 새 독립 검증 구간으로 부르지 않는다. 아직 관찰이 끝나지 않은 보유, 미정산 기업행사, 수수료 전 결과를 승률로 합치지 않는다.

## 과거 상세 투자자 분리

과거 생성기는 외국인을 명시적으로 선택한다. ‘연기금이 아닌 모든 투자자’라는 분기로 기관·사모를 외국인에 넣지 않는다. 프런트 상세 로더도 투자자·종목·날짜·중복을 검사한다. 실제 저장된 알맥 표본의734일 외국인 배열은 모두 외국인으로 확인돼 오염됐다고 주장하지 않는다. 기존 정렬 순서에서 정상이어도 순서가 바뀌면 잘못될 수 있던 잠재 분기를 회귀 테스트로 차단했다.

## 운영

정기 GitHub 수집의 readiness 통과 후 이미 검증한3개월 projection에서 관측을 기록한다. 전체 점수가 준비되지 않은 경우 첫 기록을 합성하지 않고 보류한다. 원자료·관측 파일은 비공개 GitHub와 기존 로그인 보호를 유지하며 브라우저에는 작은 집계 현황만 전달한다.30분 Codex 예약 작업은 다시 만들지 않는다.
