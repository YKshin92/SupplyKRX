# GitHub 자체 예약 수집

현재 수집과 데이터 저장은 비공개 `YKshin92/SupplyKRX-data`의 GitHub Actions에서 실행한다.
2026-10-12 사용자의 요청에 따라 cron-job.org 외부 예약 두 개를 비활성화하고 취소 표시했다.

## 실행 시간과 인증

- 평일 한국 시간 16:10, 17:10, 18:10, 20:10.
- 워크플로: `.github/workflows/collect.yml`, 기본 브랜치에서 실행.
- `COLLECTION_ENABLED=true` 저장소 변수와 기존 `KRX_ID`, `KRX_PW` Secrets를 유지한다.
- GitHub 자체 실행에는 별도 개인 액세스 토큰이 필요하지 않다. 저장에는 워크플로의 기본 `GITHUB_TOKEN`을 사용한다.
- 외부 호출용 입력과 Vercel 토큰을 요구하던 운영 검증 단계는 제거했다.
- 수동 복구는 Actions → Daily pension and foreign data → Run workflow에서 시작한다. 필요하면 start/end 날짜를 지정한다.

## 수집과 운영 반영

- 수집 오류는 최대 3번 시도한다.
- 동일 concurrency 그룹과 최근 15분 정상 수집 검사로 중복 실행을 제한한다. start를 지정한 복구는 생략하지 않는다.
- 시장·투자자별 응답 전체가 비어 있으면 운영 데이터로 저장하지 않고 다음 예약에서 다시 시도한다.
- 실제 원자료는 비공개 저장소에만 저장한다. 기존 로그인 보호와 다운로드 제한을 유지한다.
- 데이터 커밋은 기존 GitHub–Vercel 연결을 통해 배포된다.
- Vercel API를 통한 자동 재배포·운영 기준일 검사 기능은 현재 활성화하지 않는다. 관련 스크립트는 참고용이며 예약에서 호출하지 않는다.

GitHub 예약은 지연되거나 실행이 누락될 수 있어 정확한 분 단위 실행을 보장하지 않는다.
수집 코드의 재시도는 시작된 작업의 오류를 처리하며, 예약 자체의 미실행을 해결하지 않는다.
